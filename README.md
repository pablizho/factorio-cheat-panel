# 🛠 Cheat Panel — Полная панель читов для Factorio 2.0!

**Простой и мощный мод для одиночной игры и серверов.**  
**НЕ РАБОТАЕТ с достижениями** (как любой чит-мод).

## 🚀 Как открыть панель?
- **Горячая клавиша: Ctrl + F9** (в любой момент игры)
- **ИЛИ кнопка ⚠️** (в правом верхнем углу экрана, рядом с часами)

Панель **прокручивается**, имеет **поиск предметов** и **все читы из официальной вики**!

## ✨ Все функции (50+ читов)

### 📦 **Ресурсы и инвентарь**
- ✅ **Любой предмет**: Выберите из поиска + укажите количество → "Выдать"
- ✅ **Быстрые кнопки** (100+ иконок): железо, медь, платы, роботы, броня, ракеты, бочки с нефтью/кислотой
- ✅ Заполнить инвентарь (по 100 всего)
- ✅ Очистить инвентарь
- ✅ Подобрать предметы с земли (р=50)

### ⚡ **Основные читы**
- 🎮 **Cheat Mode** (бесплатный + мгновенный крафт)
- 👼 **God Mode** (бессмертие + полёт, без персонажа)
- 🧍 **Вернуть персонажа** (отмена God Mode)
- 🔬 **Исследовать ВСЕ технологии** / **Сбросить все**
- 📋 **Включить все рецепты**
- ⏩ **Завершить текущее исследование**


## 📥 Установка
1. Скачайте **ZIP-релиз** ниже.
2. Распакуйте в `%APPDATA%/Factorio/mods/` (Windows) или `~/.factorio/mods/` (Linux).
3. В игре: **Mods** → Включите "Cheat Panel" → Перезапустите.
4. **Ctrl + F9**!

## 🔧 Разработка
- **Factorio 2.0+** (Space Age).
- **Lua API**: Полный код в `control.lua`.
- **Зависимости**: Только `base`.
